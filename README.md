# مواءمة (Muwāmah) 🎓

**مواءمة** هي منصة ذكية مصممة خصيصاً لمساعدة أساتذة الجامعات والقيادات الأكاديمية على تقييم مدى توافق مقرراتهم الدراسية (Syllabus) مع متطلبات سوق العمل الحالية، باستخدام الذكاء الاصطناعي.

## 🌟 المميزات الأساسية

*   **تحليل ذكي بالذكاء الاصطناعي:** تعتمد المنصة على نماذج لغوية متقدمة (Claude API) لتحليل محتوى المقرر الدراسي واكتشاف المهارات المطلوبة في سوق العمل.
*   **استخراج النصوص من الملفات:** إمكانية رفع خطة المقرر بصيغ متعددة (PDF, DOCX) ليتم استخراج النصوص منها آلياً.
*   **نسبة المواءمة المئوية:** الحصول على تقييم رقمي يوضح مدى توافق المقرر مع الوظائف التقنية أو الهندسية المستهدفة.
*   **اكتشاف الفجوات:** عرض دقيق للمهارات المطلوبة في سوق العمل والتي تنقص محتوى المقرر الحالي.
*   **توصيات تطويرية:** تقديم مقترحات واضحة وقابلة للتنفيذ حول كيفية تحسين المقرر وسد فجوات المهارات.
*   **لوحة تحكم للمستخدم:** حفظ تلقائي لجميع التحليلات التي أجراها المستخدم للرجوع إليها لاحقاً (مدعوم بواسطة Firebase).

## 🛠️ التقنيات المستخدمة

*   **الواجهة الأمامية (Frontend):** Next.js 14, React, Tailwind CSS.
*   **قاعدة البيانات والمصادقة (Backend & Auth):** Firebase (Authentication & Firestore).
*   **الذكاء الاصطناعي (AI Engine):** Anthropic API (Claude 3.5 Sonnet).
*   **معالجة الملفات:** مكتبات `pdf-parse` (لملفات PDF) و `mammoth` (لملفات Word).
*   **واجهة المستخدم (UI/UX):** تصميم باللغة العربية بالكامل وبدعم من اليمين لليسار (RTL) مع خطوط Cairo.

## 🚀 كيفية التشغيل محلياً

### المتطلبات المسبقة
تأكد من توفر Node.js (الإصدار 18 فما فوق) ومسجل الحزم (npm أو pnpm).

### الخطوات
1. قم باستنساخ المستودع (Clone) إلى جهازك:
   ```bash
   git clone https://github.com/Rennad4/Muw-mah-.git
   cd Muw-mah-
   ```

2. قم بتثبيت الحزم البرمجية:
   ```bash
   npm install
   ```

3. قم بإنشاء ملف `.env.local` في الجذر الرئيسي للمشروع وأضف متغيرات البيئة الخاصة بك:
   ```env
   # إعدادات Firebase
   NEXT_PUBLIC_FIREBASE_API_KEY="your_api_key"
   NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN="your_auth_domain"
   NEXT_PUBLIC_FIREBASE_PROJECT_ID="your_project_id"
   NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET="your_storage_bucket"
   NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID="your_sender_id"
   NEXT_PUBLIC_FIREBASE_APP_ID="your_app_id"

   # إعدادات Anthropic (الذكاء الاصطناعي)
   ANTHROPIC_API_KEY="your_anthropic_api_key"
   ```

4. قم بتشغيل خادم التطوير:
   ```bash
   npm run dev
   ```

5. افتح الرابط `http://localhost:3000` في متصفحك لبدء الاستخدام.
